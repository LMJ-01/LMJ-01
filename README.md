## 🚀 Key Projects

### 🎬 Connected_M (영화 탐색 및 AI 분석 플랫폼)
* **Description**: TMDB 대중 데이터와 씨네21 전문 평론 데이터를 하이브리드로 통합하고, Google Gemini API 기반 챗봇으로 개인 맞춤형 영화 추천 및 심층 분석을 제공하는 플랫폼
* **Stack**: Java, Spring Boot, Python, FastAPI, React, TypeScript, GCP, Docker
* **Key Role**: 아키텍처 설계, Spring Boot 기반의 보안(OAuth2 + JWT) 인증 서버 구축, API 설계 및 독립형 AI 서버 분리 연동

### 🛡️ Fake-Buster (AI 생성 콘텐츠 판별 서비스)
* **Description**: AI가 생성한 거짓 콘텐츠를 탐색 및 분석하여 데이터 왜곡 현상을 방지하는 교육 및 정보 정화 솔루션
